# Camilla & Andreas — bryllupshjemmeside

Et helt almindeligt statisk webprojekt, klar til Vercel og uden Lovable-credits.

## Redigér indhold

Alle tekster, links, program og kontaktoplysninger ligger samlet i `public/content.js`. Erstat værdierne i firkantede parenteser før udgivelse.

## Udgiv på Vercel

1. Opret et tomt GitHub-repo og læg mappen `wedding-site` ind som repoets rod.
2. Gå til Vercel, vælg **Add New → Project**, og importér repoet.
3. Vercel genkender projektet som statisk og deployer `public` automatisk. Ingen miljøvariabler kræves.

Lokalt kan siden vises med `npx serve public` fra projektmappen.
