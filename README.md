# Camilla & Andreas — bryllupshjemmeside

Et helt almindeligt statisk webprojekt, klar til Vercel og uden Lovable-credits.

## Redigér indhold

Alle tekster, links, program og kontaktoplysninger ligger samlet i `content.js`. Erstat værdierne i firkantede parenteser før udgivelse.

## Udgiv på Vercel

1. Gå til Vercel, vælg **Add New → Project**, og importér dette GitHub-repository.
2. Vercel genkender forsiden som en statisk hjemmeside og deployer den automatisk. Ingen miljøvariabler kræves.
3. Ved senere ændringer: redigér `content.js` på GitHub, og Vercel udgiver den nye version automatisk.

Lokalt kan siden vises med `npx serve .` fra projektmappen.
